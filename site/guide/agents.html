智能体与工具

CCHarness 的智能体不是「会聊天的搜索框」，而是一个真实的工具执行循环： 模型调用工具 → 观察结果 → 继续推理，直到任务完成——每一步都在你的掌控之下。

内置工具面

绑定工作区后，智能体模式拥有 16+ 内置工具，并可通过 MCP 继续扩展：

类别工具
文件读 / 写 / 编辑 / 移动 / 删除、目录列表、文件搜索（glob / grep）
执行终端命令执行（带超时与输出截断）
网页网页抓取（经 SSRF 防护）、联网搜索
感知屏幕截取、图片多模态输入
协作子智能体委派（具名角色）、任务清单 todo_write
记忆向量记忆存取 memory_save / memory_search
扩展MCP 服务器工具、技能加载 load_skill
目标get_goal / create_goal / update_goal（目标模式）

审批与快照

  • 逐项审批：每次写 / 编辑弹出预览与行级 diff，批准或拒绝，120 秒超时自动拒绝（fail-closed）；
  • 快照留痕：每次写入保留前后快照，行级 diff 在审阅面板随时过目；
  • 完整记录：所有工具调用（含被拒绝的调用）可回溯，不丢现场。

Worktree 隔离

开启后，所有写操作重定向到 git worktree 工作树，主工作区在合并前不被触碰： 可查看完整 diff、整体合并回主区，或一键丢弃重来。适合让智能体放手尝试的高风险任务。 

主工作区 main ──────────────── 不受影响
     │
     └─ worktree cch-a1b2 ─── 智能体在这里写
              │
        查看 diff / 合并 / 丢弃

多智能体协作

  • 竞技场：一条提示词同时发给 N 个模型并行作答，泳道并排对比，逐轮 token / 缓存命中 / 成本一目了然；
  • 圆桌群聊：多成员顺序发言，主持人 LLM 负责调度发言顺序与话题收敛；
  • 子智能体：具名角色档案（独立 Provider / 模型 / 系统提示词），把独立调研子任务委派给后台——独立上下文、实时进度流式显示、完整过程落盘可查（子任务记录随所属会话删除而级联清理）；
  • 并行扇出：状态机工作流可让同一状态同时驱动多个子智能体，完成后会师综合。

上下文工程

AGENTS.md 项目约定自动注入、@ 文件引用补全、外部内容围栏包裹、 压缩上下文（70% 自动触发）——长会话不失焦，前缀字节稳定让缓存命中率不被上下文管理破坏。
