什么是 CCHarness

CCHarness 是一个自带模型（BYOM）的桌面工作台：一个界面管理多家模型服务商， 流式多会话对话，六种工作流模式按任务切换，真实智能体循环直接读写你的工作区—— 并且把前缀缓存命中率当作一级指标内置在遥测面板里。

当前能力

  • 多模型管理：内置适配 DeepSeek、智谱 GLM、Kimi、OpenAI、Anthropic、Ollama 本地模型，以及任意 OpenAI 兼容端点；连接测试、一键获取模型列表、按模型配置定价与上下文窗口。
  • 流式多会话：置顶 / 归档分组、消息分支、外部会话导入、Markdown 导出、压缩上下文（70% 自动触发 + 手动）。
  • 六种工作流模式：智能体 / 规划 / 目标 / 深度推理 / 生图 / 自定义状态机，一个下拉随时切换。
  • 真实智能体循环：16+ 内置工具读写工作区、执行命令、查网页、调 MCP；写操作默认逐项审批，全程快照留痕。
  • 多智能体协作：竞技场并行对比、圆桌群聊、子智能体后台委派、状态机并行扇出。
  • 记忆系统：向量长期记忆 + 自动反思 + AuxMemo 辅助调用精确缓存。
  • 遥测面板：命中率曲线、逐请求账本、miss 归因、成本换算。
  • 扩展生态：MCP 服务器接入、Skills 技能市场、Guardrails 注入防护。

它与网页版聊天有什么不同

能力网页聊天CCHarness
模型绑定单一厂商多家 Provider 随意切换，含本地模型
工作区手动上传文件直接读写本机目录，@ 引用补全
执行只输出文字真实工具循环：写文件 / 跑命令 / 查网页
成本黑盒订阅逐请求账本，缓存命中省钱看得见
数据存在云端全部留在本机，Key 系统级加密

适合谁

CCHarness 适合希望自主管理数据、模型与成本的用户： 需要智能体真正操作本机项目的开发者，想对比多家模型又不愿被单一平台绑定的重度使用者， 以及在意 token 花费、想看清每一分钱去向的团队与个人。

开箱即用 应用内置更新检查：点击侧边栏底部版本号即可检查新版本，也可在设置页开启启动自动检查。
