指南 / 核心概念

工作流模式

会话即工作流。输入框上方的下拉随时切换七种模式， 权限边界、指令注入与工具面随模式自动收敛——每种模式都只给它真正需要的。

模式一览

模式行为
🤖 智能体完整工具面：读写文件、执行命令、委派子智能体
📋 规划只读调研，输出方案卡；批准前不修改任何文件
🎯 目标锁定目标与验收标准，逐轮输出可核验清单，自动延续直到全部达成
🧠 深度推理思维树：三路候选方案并行生成，评审模型择优后执行
🔍 审阅三专家并行只读预审：正确性 / 安全边界 / 可维护性，汇合去重定级输出发现表
🎨 生图独立的图像生成会话，走 /images/generations 端点
🔀 自定义状态机可视化编排的声明式工作流：状态、指令、工具面与分支自定

智能体

完整的 ReAct 循环：16+ 内置工具直接读写工作区、执行命令、抓取网页、调用 MCP。 写与改默认逐项审批；切换免审批档会弹出风险确认对话框， 列明可能删除文件、清空数据等行为，勾选责任条款才能启用，档位常驻红色警示。

规划

先读后写：只读工具面先探索工作区，产出 plan 方案卡； 批准前不修改任何文件，批准后自动切回智能体模式执行。适合改动面大、需要先对齐思路的任务。

目标

对齐 Codex /goal 的完整状态机：

  • 五态生命周期：active → paused / achieved / unmet / budget_limited，持久化进会话元数据，重启存活；
  • 命令面：/goal <目标> 创建 · /goal 查看摘要 · /goal pause / resume / clear；
  • 工具化目标管理：模型可调用 get_goal / create_goal / update_goal 自主推进目标，但只能标记达成/未达成——暂停、恢复、清除是用户专属权限；
  • 证据审计：完成判定必须附可核验证据（文件路径 / 命令输出 / 测试名），存疑即未达成；
  • 预算软停止：会话成本达到上限时，下一次自动继续变为一次性收尾指令，而非硬中断。

深度推理

思维树（ToT）：对同一难题并行生成三路候选方案（稳妥 / 严谨 / 创意）， 由评审模型打分择优后再进入执行。难题不再单点赌运气。

审阅

三专家并行预审：正确性、安全边界、可维护性三个互斥的只读视角同时审查 当前任务与未提交变更（有 git diff 时自动附带）， 每位专家独立输出结构化发现——[严重度] 后果 ← 根因 @ 位置 → 验证方式。 主模型随后作为汇合评审，先只读核实、再去重定级，输出最终发现表；无法核实的条目标注「待核」。 审阅期间工具面强制只读，改与不改由你决定。

生图

走 /images/generations 端点的独立图像生成会话： 模型列表自动过滤出图像模型，结果内联渲染进对话，支持把返回的 URL 或 base64 直接显示。 图像模型与对话模型自动分流，不会互相串台。

自定义状态机

可视化编辑的声明式工作流：每个状态拥有独立的指令注入、工具面（无工具 / 只读 / 全量） 与条件分支，支持并行扇出多个子智能体会师；位置持久化，重启可断点续跑。 模型每完成一轮自动按路由推进，你也可以手动跳转状态。

工具面随模式收敛 规划模式只有只读工具；审阅模式同样强制只读；目标模式额外注入目标管理工具；状态机按状态裁剪工具面—— 模式即边界，不需要你手动开关。
