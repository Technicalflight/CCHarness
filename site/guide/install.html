下载与安装

前往 GitHub Releases 下载对应平台的安装包，自 v0.1.0 起提供三平台构建。

安装包

平台文件说明
Windows.exe（NSIS 安装向导）或 .msix64
macOS.dmgApple Silicon + Intel 通用二进制
Linux.deb / .rpm / .AppImageDebian 系 / 红帽系 / 免安装运行
未做代码签名 Windows 首次运行可能出现 SmartScreen 提示（点「仍要运行」）；macOS 首次打开需在 「系统设置 → 隐私与安全性」中放行。

应用内更新

CCHarness 内置更新检查，无需任何配置：

  • 手动检查：点击左侧侧边栏底部的版本号，即可检查并前往最新 Release；
  • 自动检查：在「设置 → 应用更新」开启启动自动检查（24 小时节流），发现新版本会在侧边栏显示更新徽标。

从源码构建

偏好命令行？克隆仓库自行构建（环境要求：Node ≥ 22、Rust ≥ 1.77）：

git clone git@github.com:Technicalflight/CCHarness.git
cd CCHarness

npm install          # 前端依赖
npm run tauri dev    # 开发模式（自动起 vite + cargo）
npm run tauri build  # 打包安装程序

单独验证：

npm run typecheck            # tsc --noEmit
npm run build                # tsc + vite build
cd src-tauri && cargo test   # 后端单元测试

首次启动

启动后进入「模型管理」添加一个 Provider（填入 Base URL 与 API Key，可用连接测试验证）， 即可在会话中选择模型开始对话。要启用智能体能力，在会话输入框处绑定本机工作区目录。
