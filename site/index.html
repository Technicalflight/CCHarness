为什么选择 CCHarness？

不是又一个聊天网页套壳——一个真正尊重你数据、时间与成本的桌面工作台。

桌面优先

原生桌面应用而非浏览器标签页：直接读写工作区文件、@ 文件引用补全、系统级通知、命令面板，会话与配置全部留在本机。

缓存是一级指标

上游前缀缓存命中 token 约 1/10 价格。CCHarness 在请求侧制造可缓存性：命中率曲线、逐请求账本、miss 归因，全部内置进遥测面板。

工作流引擎

智能体 / 规划 / 目标 / 深度推理 / 生图 / 自定义状态机——一个下拉切换，权限边界、指令注入、工具面随模式自动收敛。

Local-first 安全

API Key 经系统级加密（DPAPI / 钥匙串 / 密钥环），写操作逐项审批留痕，SSRF 防护与注入护栏默认开启，请求不经过任何第三方中转。

六种工作流模式

一个下拉随时切换，每个模式都有自己的权限边界与指令注入。

智能体

完整 ReAct 循环：16+ 工具读写工作区、跑命令、查网页、调 MCP——写操作默认逐项审批。

规划

先读后写：只读工具面先探索工作区，产出方案再动手，避免上来就改文件。

目标

对齐 Codex /goal：声明目标 + 验收清单 + 证据审计 + 预算软停，自动延续直到全部勾完。

深度推理

三方案并行生成 + LLM 评审择优（稳妥 / 严谨 / 创意），难题不再单点赌运气。

生图

直连 /images/generations 端点，结果内联渲染进对话，图像模型与对话模型自动分流。

自定义状态机

可视化编排状态、指令与工具面（只读 / 全量），支持并行扇出与条件路由，重启续跑。

不止一个聊天窗口

多智能体、记忆与安全护栏，构成一个完整的桌面 Agent 基座。

多智能体协作

  • 竞技场：多个模型同一问题并行作答，泳道对比
  • 圆桌：多模型顺序接力，前序发言注入上下文
  • 子智能体：独立上下文并行执行，具名角色可配置
  • 并行扇出：状态机一次状态同时驱动多个子任务

记忆系统

  • 向量长期记忆：embeddings + 余弦召回，每轮自动注入
  • 自动反思：回合结束自动提炼经验写入记忆
  • AuxMemo：标题 / 优化等辅助调用精确缓存，不重复计费
  • 上下文工程：AGENTS.md、渐进披露、@ 文件引用

安全护栏

  • HITL 审批：写操作变更预览 + 120 秒超时自动拒绝
  • Worktree 隔离：所有写入重定向 git 工作树，可整体丢弃
  • Guardrails：不可信内容围栏 + 注入短语检测
  • SSRF 防护：web_fetch 拒绝本机与内网地址
差异化设计

请求侧缓存工程

大模型厂商的前缀缓存按「请求前缀是否与历史一致」命中。CCHarness 把系统提示、工具定义、 会话历史拆成 三区（Zone S / H / T），静态内容前移、动态内容后置，用 SHA-256 指纹链逐请求验证字节级稳定——命中率从运气变成可运营的指标。

  • 逐请求命中账本 + 成本换算，miss 逐条归因（哪个 Zone 因为什么被打破）
  • 会话重生 / 分支 / 导入全部保持字节稳定，重启零缓存损失
  • AuxMemo 缓存标题生成与提示词优化等辅助调用，同样的钱多干一倍的活
Zone S系统提示 · 工具定义（字节稳定）
Zone H会话历史（追加式增长）
Zone T本轮消息 · 记忆注入（唯一变化点）
── 指纹链逐区验证，命中即省 90% 输入成本 ──
